### 要不要买示波器？

**现阶段不用买。** 你的调试问题 95% 是数字信号（用逻辑分析仪）和毫秒级电源跌落（用 ESP32 ADC 自己记录），示波器解决的那 5% 你现在遇不到。

| 场景 | 用什么替代 |
| --- | --- |
| I2C / UART / I2S | 逻辑分析仪（能直接解码字节） |
| 喇叭/4G 电压跌落 | ESP32 ADC 1 kHz 采样 + 串口导出 CSV + Python 画图（能连续记录 4 秒，比示波器 1 秒窗口更好用） |
| 整机功耗曲线 | 带记录的 USB 电流表 |
| 音频效果 | 耳朵 + 手机分贝仪 App |

**真正需要示波器的场景**：自己设计开关电源、调射频天线、查亚微秒级毛刺——这个项目都不会遇到。

**如果买，别买玩具**：DSO138/DSO150 这类 200 kHz 带宽的单通道设备买来就吃灰。要买直接上千元级（Rigol DS1102Z-E、二手 DS1054Z），能用十年。

**注意**：逻辑分析仪在 B1 批次已列，不要重复购买。

## 下单时最容易买错的 8 个点

| # | 坑 | 怎么避 |
| --- | --- | --- |
| 1 | 买成 **Air724UG**（无 GNSS）或裸模组 | 认准板型 `DTU_780EG`，规格里有 GNSS/独立 GPS 串口 |
| 2 | 模组刷的是 **LuatOS** 不是 AT 固件 | 下单前问客服，或刷官方 AT 固件 |
| 3 | GNSS 天线买成**无源** | 认准"有源 GNSS 天线"，带 LNA |
| 4 | IPEX 接口**代数不对**（1 代 vs 4 代） | 模组多为 IPEX 4 代（MHF4，1.2 mm），买前量一下 |
| 5 | IMU 买成 ADXL345 / MPU6050 | 认准 **LIS3DH** 丝印，I2C 地址 0x18/0x19 |
| 6 | 18650 **虚标容量**、无保护板 | 认大厂（三星/松下/力神），要"带保护板" |
| 7 | 喇叭**没有腔体** | 买"带腔体/音箱壳"的，声压差很多 |
| 8 | 用了 **IP5306 充电宝模块** | 它有小电流自动关机，待机设备会被断电 |

## 到货后的验证顺序（别跳步）

1. **只接 IMU**：I2C 扫描到 0x18 → 读 `WHO_AM_I` 应为 0x33 → 50 Hz 打印三轴。
2. **单独调 4G**：给板子接 5 V（USB 不能供电）→ 发 `AT` 回 `OK` → 查 SIM → 注网看灯 → GNSS 出 NMEA。
3. **接 ESP32**：串口互发，确认电平没问题（这一步最容易翻车）。
4. **接喇叭**：先小音量，测电压跌落，再上大音量。
5. **全部同开**：响警报的同时上行 4G，看会不会复位。

> 顺序的核心逻辑：**每次只新增一个变量**。DIY 调不通，99% 是因为同时改了两样东西。
