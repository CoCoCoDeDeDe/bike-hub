# hardware

外壳与结构件。用 OpenSCAD 参数化建模，改一个管径参数就能出新模型。

## 计划内容

| 文件 | 作用 |
| --- | --- |
| `case.scad` | 主体外壳（电路仓、喇叭孔、扎带槽） |
| `params.scad` | 管径、壁厚、长度等参数 |
| `*.stl` | 导出给切片软件（不入库，视体积决定） |

## 命令

```bash
openscad -o case.stl case.scad        # 命令行导出
```

## 设计约束

- 贴合下管或座管，内衬 2 mm TPU 减震
- 喇叭导音孔朝侧面，孔内侧贴防尘网
- 4G 模组位置留导热垫贴外壳
- 充电口用硅胶塞，不做灌封（原型要能拆）
