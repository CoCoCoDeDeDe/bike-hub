# bike-hub

> 给自行车装一个"防盗 + 定位 + 会喊话"的联网盒子。自用，顺便把嵌入式、无线、传感器、结构走一遍真项目。

bike-hub 通过 IMU、霍尔、GNSS 等传感器识别车辆被动手脚的意图，本地播放预制警报录音，同时把事件与位置推到手机上；手机端可从设备预置的录音里挑一段远程播放，形成威慑。设备用 3D 打印外壳贴合车架安装。

**当前定位**：个人 DIY 极客项目 / 能力提升载体，非商业产品。当前阶段是**概念原型**。

## 五条关键判断

1. **误报是唯一死因。** 半夜被自己装的设备吵醒两次，你就会把它关了。所以先做**影子模式**：只记录、只推送、不响，用一周真实数据校准阈值。
2. **本地闭环优先。** 地库、电梯、面包车里都可能没信号，但贼就在车边——判定和喇叭必须在设备本地完成，云端只负责"让人知道"。
3. **语音只做预置录音 + 手机选播。** 不要麦克风、不要双向对讲、不要 VoLTE（物联网卡多数禁语音）。这条链路 1–2 天能做完。
4. **先能看见数据，再谈判断。** 前两周全部投入"采数据 + 画特征分布"，不要急着联网和打外壳。顺序反了就会做出一个漂亮但判不准的盒子。
5. **多花 ¥15 买大电池和 Flash。** 未来想加码表/轨迹，这两项是唯一必须现在预留的硬件。

## 环境

当前机器（WSL2）已具备 Node 24 与 Python 3.12；PlatformIO、Docker、mosquitto 尚未安装。建议：

```bash
pip install platformio          # 固件
npm install -g node-red         # 手机端面板（不写 App）
sudo apt install mosquitto      # 本地 MQTT broker
```
